This project presents an advanced Power BI financial performance and governance dashboard designed to simulate a real-world business intelligence solution.
It focuses on analysing key business metrics such as revenue, cost, profit, and variance against targets while leveraging advanced data modelling techniques
and DAX calculations. The dashboard incorporates time intelligence (MTD, YTD, MoM, YoY), rolling averages, and dynamic measures to provide deep analytical
insights. It also includes interactive features such as drill-through, tooltips, slicers, and bookmarks to enhance user experience. Additionally, row-level security (RLS) 
is implemented to ensure controlled data access for different stakeholders. The solution is structured to support executive decision-making by answering critical questions
around what changed, why it changed, where risks exist, and what actions should be taken. Through clear data storytelling, the project transforms raw data into meaningful
business insights, demonstrating practical skills aligned with the Microsoft PL-300 Power BI Data Analyst certification,
including data preparation, modelling, visualization, and governance.
